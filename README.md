# TP1 – Programmation Orientée Objet en Python

## Objectif
Découvrir les concepts fondamentaux de la programmation orientée objet en Python.

## Notions abordées
- Création de classes et d'objets
- Attributs et méthodes
- Constructeur `__init__`
- Méthode `__str__`
- Manipulation des objets
- Dataclasses
- Décorateurs et validation des arguments

## Exercices
Le TP contient plusieurs exercices pratiques :
- Article
- Carnet
- Cercle
- Compteur de pages
- Contact
- Journal
- Convertisseur
- Produit
- Ressource
- Validation avec décorateurs
- Vecteur

- Python 3
